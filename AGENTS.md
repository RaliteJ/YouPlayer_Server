# Consignes de contribution

- Examiner Git et les fichiers concernes avant modification ; conserver le travail preexistant.
- Ne pas publier de secrets, configuration locale, donnees utilisateur, medias ou journaux.
- Coordonner les deux elements audio persistants pour le fondu ; seul l'evenement ended du lecteur actif fait avancer automatiquement la file.
- Preserver authentification, isolation par utilisateur, controles d'origine et flux prives par session.
- Les comptes admin sont reserves a la gestion ; utiliser un compte user pour la musique.
- Ajouter explicitement les nouvelles ressources statiques dans la liste d'autorisation du serveur.
- Valider les changements avec des tests cibles ; distinguer essais locaux, appareil physique et deploiement.
- Les integrations externes et la publication demandent une configuration et une action explicites.
